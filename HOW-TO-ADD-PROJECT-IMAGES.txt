MOHAMMAD AFFAN — PORTFOLIO WITH MANUAL PROJECT IMAGES

1. Upload all files and folders to the root of your GitHub Pages repository (Affan).
2. This version DOES NOT use live screenshot services. Every portfolio card has a placeholder until you add an image.
3. Put your own screenshots into: images/projects/
4. Match the filename listed below EXACTLY. Use .jpg images (recommended 1200x750 px, compressed to ~100–250 KB).
5. For PNG screenshots, either convert to JPG or edit the image src in index.html to .png.
6. You can replace screenshots at any time without editing HTML: upload a new JPG with the same filename.
7. The logo and favicon are already installed across all six HTML pages.
8. Project cards link to live websites even before you add images.
